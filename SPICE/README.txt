Οδηγός Χρήσης Προσομοιωτή SPICE (Προτείνεται περιβάλλον Linux ή Windows με WSL/MSYS2 (για υποστήριξη GCC/Make)):
1. Ανοίξτε ένα τερματικό (π.χ. Git Bash, WSL, ή CMD με υποστήριξη make).

2. Πλοηγηθείτε στον φάκελο του προσομοιωτή, π.χ.: cd C:/Users/το_όνομα_σου/Projects/SPICE.

3. Εκτελέστε την εντολή: make
Αν εμφανιστεί μήνυμα σφάλματος τύπου make: command not found, βεβαιωθείτε ότι έχετε εγκαταστήσει εργαλεία όπως MSYS2 ή WSL με υποστήριξη GCC/Make.

4. Τρέξτε την προσομοίωση: ./spice tests/test.txt όπου test.txt είναι το netlist αρχείο της προσομοίωσης και βρίσκεται στον φάκελο tests.

5. Με την εκτέλεση, θα δημιουργηθεί αυτόματα φάκελος Results/ και τα αποτελέσματα αποθηκεύονται εκεί.
